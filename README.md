# Dyslexia/Inter Typefaces for Discord
## Mobile
1. Download Shiggy Manager from https://www.shiggycord.dev/
###### If you’re rooted, you already know what to do instead of steps 1–3, but if you don’t know what that means, ignore this.
2. Locate the downloaded `.apk` and install it
3. Shiggy Manager → New Install → Install
4. ShiggyCord → Log In
5. Settings → Themes → **+** → Import from clipboard: https://raw.githubusercontent.com/Switz14/themeproject/refs/heads/main/folder/dyslexiared.json
6. Apply the theme (it’ll change your colors, but if you don’t like that, we can revert it later)
7. Settings → Fonts → **+** → Extract font from theme → Extract → Import
8. Apply the font
9. (optional) If you don’t want the custom colors: Settings → Themes → Deselect (tap the highlighted circle)
